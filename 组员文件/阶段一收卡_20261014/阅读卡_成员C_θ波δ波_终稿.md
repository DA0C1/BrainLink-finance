## 三、本维度证据汇总（供成员 E 填入《脑波-心率与状态映射关系表》）

| 数据维度      | 对应状态         | 文献证据（作者年份 + 结论要点）                                                                                                                                                                                       | 证据一致性                                                                           |
| --------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **θ 波**   | 困倦 / 疲劳 / 走神 | Tran 2020（Meta：疲劳→θ 大增 g=1.03，额/中央/后部均 g>1）；Wascher 2014（额区 θ 随任务时程持续线性上升，N 待补）；Boksem 2005（3h 任务→θ 升 + 目标导向注意受损，N=17 Ⅲ 级）；Craig 2012（疲劳→全皮层 θ 升，δ 不变）；De Gennaro 2007（40h 剥夺→额中央 θ 升）；Zhang 2018（**嗜睡驾驶→θ 下降**，方向相反） | **部分一致**：觉醒疲劳下 θ 上升证据高度一致（含 Meta，方向结论不依赖单一小样本）；但**嗜睡态 θ 下降**形成明确反例，提示"疲劳"与"嗜睡"是两种状态（见下方原因分析） |
| **θ 波**   | 记忆编码 / 注意调节  | Klimesch 1999（事件相关 θ 同步化↔编码新信息能力正相关）；Karakaş 2020（海马-皮层 θ 绑定支撑情景记忆编码-巩固-提取）；Herweg 2020（窄带 θ 特异支持联想记忆，宽带倾斜只是一般激活）                                                                                       | **一致**（机制层面），但**源于海马深部回路**，额区单通道难以复现 → 仅作机制参考，不作诊断                              |
| **δ 波**   | 深睡 / 睡眠压力    | Borbély 1982/2016（SWA/δ＝睡眠稳态过程 S 的标志，随觉醒时长累积）；Adamantidis 2019（δ 慢波＝NREM 深睡眠标志，丘脑皮层环路）；Dang-Vu 2008（慢波/δ 对应深睡中的活跃脑活动，δ 与额区响应相关）                                                                         | **一致**（δ↔深睡＝领域共识）                                                               |
| **δ 波**   | 清醒疲劳 / 嗜睡    | Lal & Craig 2002（驾驶疲劳→δ、θ 显著升）；De Gennaro 2007（睡眠剥夺→额中央 δ 升）；Zhang 2018（嗜睡驾驶→δ 升）；**Craig 2012（疲劳→δ 无显著变化）**；Tran 2020（疲劳→δ 仅小到中度变化）                                                                    | **部分一致**：δ 在嗜睡/高睡眠压力下倾向上升，但**清醒疲劳下 δ 的效应明显弱于 θ**，且有"无显著变化"的反例 → 仅作探索性指标         |
| **设备可行性** | 单通道干电极额区     | Rieiro 2019（消费级单干电极与医用级显著相关、长时稳定，差异集中在低频）；Ko 2020（单额区干电极 + 眨眼识别可准预测疲劳，r²≈0.89）                                                                                                                          | **一致**：本设备做**趋势监测**可行；但**低频段（δ 所在）是误差最大的区域**，θ 指标相对更可靠                          |


**原因分析（为什么"疲劳→θ↑"和"嗜睡→θ↓"不矛盾）**：

- **疲劳态（觉醒但资源耗竭）**：大脑为维持表现**补偿性增强**执行控制投入 → 额区 θ↑（Wascher 2014 明确将其解释为"维持表现的努力"）。
- **嗜睡态（正在滑向睡眠）**：皮层开始脱离觉醒、转入慢波主导 → 慢频（δ）上升、θ 与 α 反而被"吸走"而下降（Zhang 2018）。
- 结论：**同样叫"困"，θ 的方向可以相反**；本项目在进行状态判读时，必须先用行为/场景（是否还在主动操作、反应是否变慢）区分"疲劳"与"嗜睡"，再解读 θ。

**本维度综合判断**：

- ✅ **可支撑后续模拟程序假设**：θ 功率升高 → 觉醒期困倦/疲劳（证据强、含 Meta，且额区方向可借）；δ 升高 → 睡眠压力/嗜睡倾向（机制明确、多篇一致）；BrainLink 类设备的**趋势监测**得到直接文献支持。
- ⚠️ **仅作探索/需谨慎**：θ 与记忆编码（源于海马，额区难复现）；清醒疲劳下的 δ（效应弱、易受眼动/肌电伪迹污染，且消费级设备低频误差最大）；"θ 一律等于困倦"（嗜睡反而下降）。
- 🔧 **落地建议**：对 δ 采用"重点清洗 + 打标不硬判"策略（结合陀螺仪/眨眼识别剔除伪迹，参考 Ko 2020 把伪迹转为特征）；状态判读用 **θ / δ / 心率 + 行为场景**多指标交叉，不单用 δ。

## 四、θ 波与 δ 波的作用总结（本维度核心结论）

> 频段定义以 BrainLink 出厂口径为准：**δ ≈ 0.5–4 Hz**、**θ ≈ 4–8 Hz**（与 `brain_sim.py` 一致）。

### θ 波（4–8 Hz）——「清醒与睡眠之间的过渡节律」

| 面向          | 作用                                                                   |
| ----------- | -------------------------------------------------------------------- |
| **主导状态**    | 困倦、浅睡/入睡过渡、走神、冥想、深度放松但清醒                                             |
| **疲劳监测**    | 最稳健的疲劳标志：精神疲劳后 θ 增幅为全频段最大（Meta g=1.03）；**额区 θ 随任务时程持续上升**，是"还在硬撑"的信号 |
| **认知功能**    | 事件相关 θ 同步化与**新信息编码能力**正相关；经海马-皮层回路支撑情景记忆的编码-巩固-提取；也参与注意调节            |
| **注意的反例**   | 疲劳（仍清醒）时 θ↑；但**嗜睡（滑向睡眠）时 θ↓** —— 方向取决于状态                             |
| **情绪/临床关联** | 冥想（尤其额中线 θ, FMθ）升高，反映维持内省专注所需的控制；θ 异常升高也见于多种神经精神疾病                   |

### δ 波（0.5–4 Hz）——「深睡与睡眠压力的标志」

| 面向         | 作用                                                                       |
| ---------- | ------------------------------------------------------------------------ |
| **主导状态**   | 深睡（NREM 慢波睡眠）、无意识状态；清醒时几乎不占主导                                            |
| **睡眠稳态**   | 慢波活动（SWA/δ）即"睡眠压力"的量化指标：随觉醒时间累积上升、入睡后指数下降（双过程模型的 S 过程）                   |
| **深睡功能**   | 慢波并非"大脑关机"，而是**活跃的同步状态**，与记忆巩固、脑内代谢废物清除（类淋巴系统）、恢复密切相关                    |
| **清醒时的意义** | 清醒态下 δ 异常偏高，多提示**睡眠不足 / 睡眠压力大 / 极度困倦**，或脑电被眨眼、肌电、体动伪迹污染 —— **不等于"正在深睡"** |
| **测量风险**   | 低频段最易被伪迹污染；消费级单通道干电极在低频段的误差最大（Rieiro 2019 明确指出）→ 本设备测 δ 需最谨慎             |

### 一句话对照

|         | θ 波               | δ 波                 |
| ------- | ----------------- | ------------------- |
| 频率      | 4–8 Hz（稍快）        | 0.5–4 Hz（最慢）        |
| 主场景     | 困倦、走神、记忆编码、冥想     | 深睡、睡眠压力累积           |
| 疲劳时     | **上升**（证据最强，额区可借） | 上升但效应弱、易受伪迹         |
| 嗜睡时     | 反而**下降**          | 上升                  |
| 对本项目的价值 | ★★★ 可作核心疲劳/困倦指标   | ★★ 作睡眠压力/嗜睡的探索性辅助指标 |
