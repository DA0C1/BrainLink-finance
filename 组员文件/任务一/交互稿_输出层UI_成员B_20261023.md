## 三、交互清单

### 点击
- 模式切换（自动/手动/粘贴）、三个抽屉入口、明暗主题
- 播放/暂停/单帧/重置
- 主界面卡片「→」入口：详细判别 / 图例·A·B 对照 / 全部提醒·决策模拟
- 8 状态网格点击注入该相位；提醒中心级别筛选；决策模拟（买入/卖出/持有）→ 冲动判定 → 更新 calmness；A/B 段切换；曲线视图切换
- 注入伪迹帧（验证"打标不硬判"）

### 拖拽
- **优先级仲裁队列**：上下拖动重排；松开后立即用当前帧证据重算仲裁结果并提示 `原状态 → 新状态`；顺序持久化；方向键可访问；一键恢复默认
- 提醒弹窗可拖动摆放（拖动后取消自动关闭）；桌面角标可挪位（阈值防误触）

### 切换
- 数据源模式、浅/暗主题、任务态 `task_active`、语音、免打扰、桌面通知、ADAPT、疲劳演示加速

### 表单与输入
- 判别参数滑杆（实时生效，写 localStorage）；语音音色/语速/音量/试听；通知权限申请（含降级提示）
- 粘贴 JSONL：逐行校验，非法行高亮 + 定位行号 + 跳过计数，载入后逐帧播放

### 动画
- 置信度环形 SVG 补间、状态切换弹跳、提醒滑入/淡出、z-score 双向生长、冷却条填充、曲线渐变面积 + 着色带 + 打点

## 四、边界情况处理

| 场景 | 处理 |
| --- | --- |
| 抽屉关不掉（已修复） | 类选择器 display 覆盖 `[hidden]` 的坑，已加 `[hidden]{display:none!important}` 兜底 |
| 刚打开无决策数据 | 曲线预热 65 点基线；无决策时 calmness=1.00 显示"—" |
| `beta=0` / 窗口未填满 | 特征返回 Infinity/NaN，门控跳过不硬判；z 条显示"窗口未满" |
| 伪迹帧 | 命中 8×/15× 门限 → 不更新平滑、不进特征窗，状态保持上一帧，计数 +1 闪动 |
| 粘贴非法 JSON/缺字段/theta≤0 | 逐行校验定位行号，非法行跳过；字段缺失取默认 |
| 粘贴播完 | 自动停止，不空转 |
| Notification/SpeechSynthesis 不可用 | 特性检测 + try/catch 静默降级，界面如实提示 |

## 五、口径说明（答辩提示）

- 决策模拟冲动判定带 `conf ≥ 0.7`（弱判别阈值）门槛；`output_demo.py` 无此门槛——两者口径不同，答辩时注明。
- 曲线字段内部命名为 `t/calm`（源头 `engine.calmness` + 仿真时钟），与验收清单 `ts/calmness` 同源同义。
- 8 段演示剧本顺序：UI 自动轮播（mock.js `AUTO_TOUR`）为 focus→flow→distracted→relaxed→stress→anxiety→fatigue→drowsy（**flow 在 focus 后第 2 位**，按"由好到坏"编排）；`output_demo.py` 剧本为 focus→distracted→relaxed→stress→anxiety→flow→fatigue→drowsy（**flow 第 6 位**）。**两剧本顺序不同属合法差异**（UI 轮播侧重状态遍历、output_demo 侧重状态时长窗口），答辩按各自文件引用。
