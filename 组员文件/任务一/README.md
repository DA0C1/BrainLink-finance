## 一、快速运行

**双击 `index.html` 即可**（无需服务器、无需联网、无第三方依赖）。

也可用任意静态服务器打开，例如：

```bash
cd 任务一
python -m http.server 8080      # 然后访问 http://localhost:8080
```

> 说明：本界面全部使用**普通 `<script src>` 加载**（非 ES Module），因此 `file://`
> 直接双击打开也能正常加载 CSS/JS，不存在跨域限制。仅 **桌面通知（Notification API）**
> 受浏览器安全策略限制，在 `file://` 下通常不可用 —— 界面会如实提示"该环境不支持"，不影响其余功能。

### 1.1 接真机（三步）

1. 启动数据桥（串口 → 浏览器，只监听本机）。**推荐直接双击项目根目录的 `启动-实时面板.cmd`**，
   按提示选 `2`（真机）再输入 COM 号 —— 脚本会自动带上内置 Python 与正确参数。
   手动启动等价于在 **`项目文件/`** 目录下执行：
   ```bash
   python live_bridge.py --source serial --serial-port COM5 --baud 115200
   ```
   > `--port` 是 HTTP 端口（默认 8770），串口名要用 `--serial-port`，别写混。
2. 界面顶栏点「**校准**」→ 三段采集（A 闭眼 / B 睁眼静坐 / C 闭眼放松）→ 看报告 → 「导出基线」。
3. 顶栏模式切「**真机/回放**」→ 校准抽屉填桥地址 `http://127.0.0.1:8770` → 「连接」。

> **顺序不要颠倒**：先校准再收帧。没校准时判据用的是 mock 默认基线（报告里 `theta_ref_src = default`），
> 判出来的状态与受试者无关。

> **使用说明**：每个区块的名称作用、开关 disabled 操作、每项数据的含义/单位/更新方式与计算口径，见 **`使用说明.md`**（按区块条目化，可对照页面阅读）。

## 二·五、视觉规范（v3.12）

方向：**工业实用 / 临床仪器面板**。可信感来自结构（发丝线、对齐、等宽数字），
不来自阴影与渐变。

| 维度 | 规范 |
|---|---|
| 字体 | 数字与拉丁：`Bahnschrift`（DIN 1451，Win10/11 自带，离线可用）；中文：`Microsoft YaHei UI`；键名：`Cascadia Mono`。中文标题不做大写变换 |
| 字号 | 7 档：10.5 / 11.5 / 12.5 / 14 / 15 / 18 / 30（`--fs-micro … --fs-display`） |
| 数值 | 全部 `font-variant-numeric: tabular-nums`，刷新时不跳列宽 |
| 间距 | 4px 基准：4 / 8 / 12 / 16 / 24 / 32 / 48（`--sp-1 … --sp-7`） |
| 圆角 | 5 档：3 / 8 / 10 / 14 / 999（`--r-xs … --r-pill`） |
| 阴影 | 只留 2 档且极轻；卡片层次由 1px 发丝边框承担 |
| 颜色 | 品牌蓝为唯一强调色；红=告警、橙=注意、绿=良好、灰=中性，语义固定不借色 |
| 底纹 | 32px 发丝网格（`--grid-line`），透明度 2.8%–3.5%，只做尺度参照 |
| 图标 | `js/icons.js`：24×24 视框、stroke 1.7、圆头、`currentColor`；状态符号 9 个各有所指 |
| 动效 | 微交互 160ms / 常规 300ms，缓动 `cubic-bezier(.16,1,.3,1)`；**交互不位移**，用底色 + 内阴影表达按压；全部受 `prefers-reduced-motion` 约束 |

> 为什么不用 emoji：Windows 上由 Segoe UI Emoji 渲染，字重、基线、彩色填充都不受控，
> 深色主题里尤其突兀，且无法跟随 `currentColor`。自绘 17 个符号后，图标才和文字同一套语言。

## 四、边界情况处理（均已实测）

| 场景 | 处理 |
| --- | --- |
| **抽屉关不掉（已修复）** | 根因：`.drawer{display:flex}` 与角标计数 `.bdg-count{display:grid}` 这类**类选择器的 display 会盖掉浏览器默认的 `[hidden]{display:none}`**。已在 CSS 加全局 `[hidden]{display:none!important}` 兜底，现三种关闭方式（✕ / 遮罩 / ESC）均生效，并新增抽屉内标签与「再点同按钮关闭」 |
| 刚打开、无决策数据 | 曲线经预热即有 65 点基线；无决策时 calmness = 1.00 并显示"—" |
| `beta = 0` / 窗口未填满 | 特征返回 `Infinity`/`NaN`，门控跳过不硬判；z 条显示"窗口未满"而非脏数据 |
| 伪迹帧 | 命中 8×／15× 门限 → 不更新平滑、不进特征窗，状态保持上一帧，计数 +1 并闪动提示 |
| 粘贴非法 JSON / 缺字段 / theta ≤ 0 | 逐行校验，定位错误行号，红框提示，非法行跳过；字段缺失自动取默认 |
| 粘贴数据播完 | 自动停止播放，不再空转（不报错） |
| Notification / SpeechSynthesis 不可用 | 特性检测 + try/catch 静默降级，界面如实提示 |
| localStorage 不可用（隐私模式） | 读写包裹 try/catch，降级为不持久化 |
| 冷却倍率设为 0、参数取极端值 | 已在 min/max 全区间遍历，无异常、无 NaN 渲染 |
| 指针移出列表/画布后松手 | document 级 pointerup 收尾，不会残留浮层克隆或卡住拖拽态 |
| 后台标签页回来后补帧 | 单帧最多补 6 帧，防止 rAF 暴走 |
| 基线缺关键特征 | 构造时抛错（含 delta，嗜睡 δ 佐证依赖） |

## 五、运用的模型（判别与决策）

| 模型 / 算法 | 说明 | 出处 |
| --- | --- | --- |
| **可解释线性加权判别** | 8 状态各一条 `score = Σ wᵢ·z(特征ᵢ)`，**刻意不用 NN/GBDT 黑盒**，保证每条规则可溯源 | 设计文档 §五 |
| **个体 z-score 偏离模型** | 全特征相对校准基线 μ/σ 判偏离（非绝对阈值），含 σ_min 下限保护 | §三 基线层 / v2.1 |
| **门控 + 优先级仲裁 + 时间确认** | 门控定资格，优先级定胜负（`stress > anxiety > drowsy > fatigue > distracted > flow > focus > relaxed`），5s 活窗命中率 ≥0.6 抑制抖动 | §三 判别层 / v2.7 |
| **时间确认口径（v2.8.4 补注）** | neutral 帧不进入命中缓冲（数据不足不稀释候选确认）；1:1 抖动（如 stress/neutral 交替）因 neutral 不计数而不会抑制为 neutral——命中率只统计候选状态帧，答辩时按此口径说明 | §三 判别层 / v2.7 |
| **EWMA 平滑**（α=0.2） | EEG 快变特征去抖 | SDK 指南 4.2 |
| **伪迹剔除**（单频段 8× ／ R_tb 比值 15×） | 比值门限独立放宽，防真实状态切换被误杀导致 I_f 永不积分 | v2.8 缺陷 m |
| **时间戳滑动窗** | EEG 10s / RR 60s / GYRO 30s，按秒截断（真机 RR 回调 3 值/次，按元素计数会只覆盖 24–27s） | v2.7 #7 |
| **RMSSD 组内差分**（60s 慢窗 + 30s 快窗） | 压力/放松用 60s，恐慌速率用 30s；跨回调批次断开差分 | 特征层 / v2.6 #5 |
| **疲劳积分 I_f** | `dI/dt = (θ_norm−1.2) − I/300`（触发阈值 IF_THETA_NORM=1.2，τ=300 时间常数收敛，`exp(-dt/300)` 积分）；θ_ref 冻结为校准基线（防止滚动基线"吃掉"疲劳） | v2.8 / v2.2 缺陷 15 |
| **派生同步率**（窗口 10 帧同向帧占比 ≥0.6 + 锁存） | 用于心流"趋势一致性"，**官方无此独立字段，属工程派生口径** | 指南 2.2 / v2.6 |
| **置信度线性映射 + clamp [0.6, 0.95]** | 双绝对值分母兼容负分；疲劳/嗜睡走自身门控余量特判 | v2.2 / v2.8 缺陷 n |
| **反馈策略（状态机 + 冷却 + 弱判别升级）** | 强/中 60s、轻 30s 冷却；conf<0.7 仅记录，持续 60 帧升级一次 mild | 反馈层 / v2.6 #3 |
| **个体基线自适应 ADAPT**（默认关闭） | EWMA α=0.001、单次限幅 ±0.5σ，仅无状态命中帧更新 | v2.8 #9 |
| **理智度 A/B 对照** | 冷静度 = 1 − 冲动操作数/总决策数；无干预段 vs 有干预段配对比较 | §三 理智度指标 |
| **干预依据：Laborde 2022 深呼吸** | stress / anxiety 话术的放松训练依据 | v2.6 文献审计 |

## 六、运用的应用与接口

| 应用 / 接口 | 用途 |
| --- | --- |
| **BrainLink 单通道额区干电极 EEG** | 原始频段功率（δ/θ/α/β/γ）+ 官方 attention/meditation 指数（指南 2.1/2.2） |

## 八、口径与免责（答辩须知）

### 8.1 八态判据的证据强度分级（v3.14 补）

**8 个状态不是同一强度**。主动摊开比被问出来好：

| 等级 | 状态 | 判据与依据 |
|---|---|---|
| **A（有直接文献阈值）** | `stress` | `z(RMSSD₆₀) < −1.5`，HRV 应激反应的文献值（Stephenson 2021） |
| **B（共识 + 工程门控）** | `drowsy` | `z(TAR)>+1.5` 且 `z(δ)>+1.0`（θ/α 升高 + δ 佐证，嗜睡共识） |
| | `relaxed` | `z(A_rel)>+1.5`（α 升高=放松；A_rel 是相对基线的派生增量） |
| | `focus` | `z(R_tb)<−1.0` + RMSSD 不低 + 体动平静（θ/β 负相关有依据，"排除法"三条件为工程构造） |
| | `distracted` | `z(R_tb)>+1.0`（与 focus 共用 R_tb 两端，区分依赖单一特征） |
| **C（工程派生口径）** | `anxiety` | `att<40 且 med<40`——用厂商黑盒指数定义焦虑，无独立效度验证 |
| | `fatigue` | `z(R_ba)<−1.0` 且 `I_f≥300s`——R_ba 是工程比值，300s 是"人定当量"非统计量 |
| | `flow` | `att/med>60` + 稳定 5 帧 + sync 达标——`sync` 官方无此字段 |

**建议表述**：A 档可说"判定"；B 档说"符合该状态的生理模式"；C 档说"与该状态一致的模式"，
不宜说"诊断出"。

### 8.2 已知的判据耦合（v3.14 实测）

`R_ba = β/(α+θ)`，要让它低（疲劳门控）只能 β↓ 或 α↑：

- β↓ ⇒ `R_tb = θ/β` 必然↑ ⇒ **distracted 门控同时成立**
- α↑ ⇒ `A_rel` 必然↑ ⇒ **relaxed 门控同时成立**

置信度 `conf = 0.6 + 0.35·sep·strength`，`sep` 与第二名比 —— 三态共现时分母变大、conf 被稀释。
构造式实测：强疲劳场景 conf **0.61–0.64**（< 弱判别阈值 0.7，只记录不提醒）；
真实 mock 疲劳段 0.75（刚过阈）；其余 6 态 0.83–0.95。

**后果**：若受试者"疲劳且放松"（累到不想动，α 高 β 低），疲劳可能只记录不干预。
**未修**（改动会影响已验收的 8 段主判率），列为此后的优先改进项。

### 8.3 其他口径

- **派生指标**：同步率 `sync_ratio` 为本实现派生口径，**官方无独立同步率字段**。它靠相邻帧差分方向
  计算，att/med 完全恒定时无定义 → `flow` 判不出（实测恒值 75 → neutral，正弦同向 → flow 0.95）。
- **neutral 占比**：真实序列约 **25%**（765 帧里 194 帧）。门控全为合取，不确定即判 neutral ——
  对"不打扰"是正确取舍，但对外说明"8 态判别"时须同时给出这一覆盖率。
- **经验初值（非文献值）**：I_f 积分触发 300s、半衰期 600s、`SLEEP_MIGRATE_S`、`ADAPT_*` 均为经验初值；`baseline_adapt` 默认关闭。
- **肌电门默认关闭**：`ARTIFACT_EMG_GATE=False`。V4 真机已验证：朗读时 **δ 升 9.4×、θ 2.7×、β 仅 1.2×**，
  伪迹走低频位移通道，β+γ 肌电门无效（拦截率 10%）。因此保持关闭，并在协议上要求任务期间不发声；
  该限制会让说话段的 TAR/δ 升高（v3.16 校准改用窗口估计量后，V4_TALK 会更明显地落到 drowsy）。
- **v3.16 校准估计量变化带来的分布变化（答辩须知道）**：band 派生特征的 μ/σ 改用 **10 秒窗均值**估计，
  与运行时同一把尺。此前校准用逐帧、运行时用窗均值，实测 σ 差 **2.3–3.4 倍**，等于判据灵敏度被压掉 2–3 倍
  （D2_B 的 122 帧里 focus 判 0 帧）。改正后的真实分布：
  - D2_C：relaxed 114→**79**，新增 focus 22、neutral 19；
  - V4_TALK：distracted 24→**drowsy 24**（朗读 δ 升 9.4×，15× 伪迹门抓不到，旧逐帧 σ 把这个偏移压掉了）；
  - `c_anchor_z` 3.42→**12.49**。
  **这两处不是回归，是灵敏度恢复后暴露的已知口径问题**；V4_TALK 的 drowsy 不代表真实困倦。
- **设备限定**：如有引用 "F1=89%" 系 EPOCX 14 通道**被试内**结果，单通道额区不可复现。
- **演示加速（可在设置中关闭）**：疲劳 I_f 自然累积到 300s 约需 10 分钟。为使演示在合理时间内可观察，进入疲劳段时**预置 I_f = 270s**，其余部分仍为自然累积。
  **该操作只动计数器初值，不改动任何判据、阈值或话术。**
- **mock 数据仅验证管道与界面，不验证判别准确性**（设计文档 §七 已明示，答辩须主动说明）。
- **决策模拟口径**：界面「决策模拟」对冲动判定带 `conf ≥ 0.7`（弱判别阈值）门槛；组长演示 `output_demo.py` 无此门槛——两者口径不同，答辩时注明（弱判别仅记录、不视为冲动决策）。
- **v2.8.3（组长侧同步）**：JS 引擎 `_extract` 补 `alpha/delta` 特征字段，基线自适应 ADAPT 覆盖范围由 7 项对齐 Python 的 9 项；Node 实测 8 段回归 + ADAPT 专项全过。
- **v2.8.4（组长侧注记）**：时间确认口径——neutral 帧不计入命中缓冲，命中率只统计候选状态帧。
- **v2.8.5（组长侧同步）**：粘贴回放 RR 增加生理范围过滤（300–2000ms，与真机 pushRR 对齐）；localStorage 偏好值域校验（坏值回落默认，防 step=0 导致时钟不走）。
- **v2.8.5b（组长侧修复）**：默认基线 `theta_ref` 100→55，对齐 Python `calibrate_from_mock`（A 段 θ 中位数≈55）——此前差 2 倍致 I_f 疲劳积分速率双引擎不一致（JS 靠演示预置掩盖），修复后同帧序列触发点一致。
