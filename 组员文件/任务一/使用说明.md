# 盯盘状态提醒界面 · 使用说明

> 适用版本：`任务一/output_ui/`（index.html + css/styles.css + js/engine.js + js/mock.js + js/app.js）
> 阅读方式：本文档按**界面区块**逐条列出「名称与作用 → 打开/关闭/切换/刷新操作 → 每项数据的含义、单位与更新方式」，可直接对照页面阅读。

## 0. 运行与总览

### 0.1 如何运行

| 步骤 | 操作 |
| --- | --- |
| 打开 | 双击本目录下的 `index.html`（用普通 `<script src>` 而非 ES Module，`file://` 下可直接打开，无需起服务） |
| 无第三方依赖 | 页面离线可用；仅「桌面通知」在 `file://` 下多数浏览器不可用，会显示降级提示 |
| 如需完整能力 | 用浏览器访问本地 http 服务（例如在该目录执行 `python -m http.server`），再打开 `http://localhost:8000/index.html` |

### 0.2 界面的三层展示层级（本次重构的核心约定）

| 层级 | 位置 | 放什么 | 目的 |
| --- | --- | --- | --- |
| **主界面** | 页面主体 | 「状态」「核心指标（5 项）」「理智度曲线」「最新提醒」 | 一目了然，盯盘时余光可读 |
| **抽屉 · 详情** | 右侧滑出面板 | 运行读数、次要指标、8 状态判别网格、优先级队列、z-score、冷却监视、图例、A/B 对照、决策模拟、角标预览、**全部提醒** | 详细数据与判别过程，需要排查/演示时再打开 |
| **抽屉 · 设置** | 右侧滑出面板 | 数据流控制、判别参数、提醒通道、粘贴数据、疲劳演示工具 | 次要参数与高级选项，日常不改动 |
| **抽屉 · 校准** | 右侧滑出面板 | 当前基线摘要、三段校准（A/B/C）与进度、校准报告、导入/导出基线、数据桥地址与连接 | **真机使用前必做**；mock 演示可忽略 |

抽屉四个面板：**详情 / 设置 / 校准 / 说明**（模型、接口、技术栈与免责条款在「说明」面板）。

## 1. 顶栏区块

### 1.1 品牌区（左侧）

| 项目 | 说明 |
| --- | --- |
| 名称与作用 | 显示产品名「脑状态盯盘助手 · 输出/提醒层」与副标题；左侧圆形标识在数据到达/状态切换时会做一次脉冲动画，作为「有新数据」的视觉提示 |

### 1.2 数据源模式切换（中段四选一）

| 按钮 | 切换后行为 | 适用于 |
| --- | --- | --- |
| **自动轮播** | 按内置演示脚本依次经过 8 个状态相位，覆盖完整识别链路 | 首次演示、答辩录屏 |
| **手动注入** | 固定在你指定的相位持续出帧（在「详情 → 8 状态判别网格」点某个状态即可注入） | 逐个验证单一状态 |
| **粘贴数据** | 用「设置 → 粘贴帧数据」载入的真实/外部帧逐帧回放 | 复现真实日志 |
| **真机/回放** | 从本地数据桥（`live_bridge.py`）按真实节奏收帧，引擎时钟按**真实帧间隔**推进 | 真机联调、录制回放 |

- **打开/切换**：直接点对应按钮；当前生效的按钮为蓝色高亮。
- **边界**：切到「粘贴数据」但尚未载入任何数据时，会**自动打开「设置」面板**并提示「请先在『设置 → 粘贴帧数据』中载入数据」，不会报错、也不会卡住。
- **刷新**：模式切换本身不重置引擎；要清干净请点「重置」。

#### 1.2.1 「真机/回放」怎么接线

浏览器不能直接读串口，所以真机数据由**本地数据桥**转发（SSE 逐帧推送）：

```bash
# 以下命令都在「项目文件/」目录下执行（live_bridge.py 不在本目录）

# 真机（BrainLink TGAM，串口 115200）。注意：--port 是 HTTP 端口，串口名是 --serial-port
python live_bridge.py --source serial --serial-port COM3 --baud 115200

# 录制回放（答辩演示用，可循环）
#   data/ 里是 collect_real 的 .jsonl，回放要先用 export_csv.py 转成 CSV：
#   python export_csv.py data/real_sub01_20261110_211436.jsonl -o data/demo.csv
python live_bridge.py --source replay --csv data/demo.csv --speed 1 --loop

# 纯合成（只验证链路，不代表判别准确率）
python live_bridge.py --source mock
```

然后在「校准」抽屉的「桥地址」填 `http://127.0.0.1:8770`，点「连接」。

> 局域网/公共场合演示：启动加 `--token 随机串`，桥地址填 `http://127.0.0.1:8770/?token=随机串`。
> 静态页不校验令牌，但 `/stream` 与 `/health` 会 401；UI 会从地址栏记住 token。

- 桥默认只监听本机（`127.0.0.1`），实验数据不出机器；目录外访问与路径穿越一律 404；
- 顶栏提示会显示连接状态与最近帧间隔；队列上限 300 帧，积压时丢旧帧而不是卡死；
- 真机模式**不做预热**——预热会伪造出一段并非来自受试者的"稳态"，污染后续判据。

#### 1.2.2 「校准」抽屉：三段校准

真机使用前**必须**校准，否则判据用的是 mock 默认基线（`theta_ref_src = default` 就是警示）：

| 段 | 快速模式 | 完整模式 | 受试者指令 | 产出 |
| --- | --- | --- | --- | --- |
| A 闭眼静息 | 15s | 30s | 闭眼、不想事、不说话 | δ 基线 + `theta_rest`（仅参考） |
| B 睁眼静坐 | 40s | 120s | 睁眼看十字、不做任务 | 全部 z 基线 + **`theta_ref`** |
| C 放松 | 40s | 120s | 深呼吸、肩放松 | 放松锚点 `c_anchor_z`（校验放松态可否判） |

- **快速模式只用于联调**：时长按协议等比压缩，B 段仍保留 40s（约 33 帧）以保证 σ 有个样子；
  但正式采集**必须**用完整模式——B 段是全部 z 基线的来源，样本越薄 σ 越不可靠。
- 校准结束给**报告**：段样本数 / 伪迹率 / `theta_ref` 与来源（`B` / `A-fallback` / `default`）/ 放松锚点 z / β·γ 参照 / 告警列表。
- 「导出基线」得到 `baseline.json`（一人一份，不跨人复用）；「导入基线」热替换——清派生状态、保留日志与统计。
- 伪迹帧不进入校准采集，否则肌电/眨眼会把中位数带偏。

## 2. 控制条区块（已精简）

### 2.1 区块作用

只保留**核心推流操作**。仿真步长、推流速度、任务态、语音、免打扰、注入伪迹等已移入「设置 → 数据流控制」，右侧给出迁移提示。

### 2.2 按钮逐项

| 控件 | 作用 | 状态/反馈 |
| --- | --- | --- |
| **开始推流 / 暂停推流** | 连续按「推流速度」出帧 | 播放中按钮变红且文案为「暂停推流」；粘贴数据播完后会自动停止 |

### 2.3 数据更新方式

- 播放时：按设定的帧率逐帧刷新（上限 20 帧/秒）。
- 单帧：每次点击刷新一次。
- 暂停时：界面保持最后一帧状态不变，**不会**随时间变化（除非调整设置/筛选/打开抽屉）。

## 3. 主界面区块一：状态展示区

### 3.1 区块作用

回答两个问题：**现在是什么状态？有多确定？** 下方配 5 项最能反映生理主线的核心指标。

### 3.2 状态主卡

| 显示元素 | 含义 | 单位 / 取值 | 更新方式 |
| --- | --- | --- | --- |
| 大图标 | 当前状态的表情化指示（🎯专注 / 🌊心流 / 🍃放松 / 💭分心 / 🪫疲劳 / ⚡压力 / 🌫️焦虑 / 😴嗜睡 / ⏳中性） | 枚举 | 状态变化时弹跳动画刷新 |
| **环形进度（中心数字）** | **置信度 confidence**，反映该判别的确定程度 | 无量纲，**0.60 ~ 0.95**（线性映射后 clamp） | 每帧刷新，环形有 0.45s 过渡动画 |
| 环形颜色 | 跟随状态族着色：**绿=良好**（focus/flow/relaxed）、**橙=注意**（fatigue/distracted）、**红=干预**（stress/anxiety/drowsy）、**灰=中性** | — | 随状态变化 |
| 状态中文名 + 英文键 | 例如「压力 / stress」；`neutral` 显示为「中性/未确认」 | 枚举 | 每帧刷新 |
| **级别徽章** | 本次输出的提醒级别：`silent`（不打扰）/ `mild`（轻提醒）/ `calm`（建议干预）/ `strong`（预留，当前 8 状态不会触发） | 枚举 | 每帧刷新 |
| 冷却徽章 | 该状态处于冷却期时出现，倒计时结束后消失 | 秒（s） | 每帧刷新；为 0 时自动隐藏 |
| 建议话术 | 该状态对应的输出文本（v2.8 原文，未在界面层改动） | 文本 | 每帧刷新；冷却期内显示「冷却中」、弱判别显示「弱判别，仅记录状态」 |

**计算口径**
- 置信度：由仲裁得分线性映射后 clamp 到 `[0.6, 0.95]`；状态被时间确认否决为 `neutral` 时固定为 `0.60`。
- 状态来源：8 条候选各自先过**门控**（资格），再由**优先级仲裁**取最高优先级的一条，最后经**时间确认**（5s 活窗内命中率 ≥ HIT_RATIO=0.6）才输出；通不过则显示 `neutral`。

### 3.3 核心指标（5 项）

| # | 名称 | 含义 | 单位 | 计算口径 | 更新方式 |
| --- | --- | --- | --- | --- | --- |
| 1 | **att / med** | BrainLink 官方注意力 / 冥想指数 | 0–100 整数 | 取**最近一帧原始值**（未平滑），用于焦虑/心流的绝对判据 | 每帧刷新 |
| 2 | **R_tb (θ/β)** | θ 与 β 的功率比，专注/分心的主判据 | 无量纲 | 10s EEG 时间戳滑窗内 θ、β 均值再相除（先经 EWMA α=0.2 平滑） | 每帧刷新 |
| 3 | **RMSSD₆₀** | 60s 窗内 RR 间期差值均方根，压力主判据 | 毫秒（ms） | 组内差分（跨回调批次断开），样本 < 8 时显示「窗口未满」 | 每帧刷新；窗口未满显示占位文案 |
| 4 | **HR** | 心率 | 次/分（bpm） | 优先用设备 `heart` 字段的 EWMA 值，否则用 60s 窗均值 RR 换算 `60000/meanRR` | 每帧刷新 |
| 5 | **I_f 积分** | 疲劳积分（θ 相对冻结基线的累积偏离） | 秒（s），显示为 `x / 300s` | θ_norm>1.2 时累加 `(θ_norm−1.2)·dt`，并按半衰期 300s 衰减；≥300s 才可能触发疲劳 | 每帧刷新；可在「设置 → 疲劳演示工具」快进/归零 |

### 3.4 底部入口

| 按钮 | 作用 |
| --- | --- |
| **查看详细判别 →** | 打开「详情」抽屉，内含 8 状态网格、优先级队列、z-score、冷却监视等 |

## 4. 主界面区块二：理智度评分曲线

### 4.1 区块作用

给出**「操作是否冷静」的量化曲线**：累计冷静度 + 近期趋势，是盯盘复盘的核心指标。

### 4.2 数据逐项

| 显示元素 | 含义 | 单位 / 取值范围 | 计算口径 | 更新方式 |
| --- | --- | --- | --- | --- |
| **calmness 累计（大数字）** | 累计冷静度 = 1 − 冲动操作次数 / 总决策次数 | 0.00–1.00（无决策时为 1.00） | 每次点「买入/卖出/持有」才记账，不出帧不变化 | 每次决策后刷新 |
| 趋势行 | 近 24 帧内冷静度的前后半段差值 | 百分点（pt） | `后半均值 − 前半均值`，>0.01 记回升、<−0.01 记下滑 | 每帧刷新 |
| 近 10 次滚动 | 最近 10 次决策的滚动冷静度（比累计值更敏感） | 0.00–1.00 | 窗口大小 10；样本不足显示「近 10 次决策 —」 | 每次决策后刷新 |
| 数字颜色 | ≥0.8 绿、0.5–0.8 橙、<0.5 红 | — | — | 随值变化 |

> **注意**：这里的「决策」指在「详情 → 决策模拟」点击买入/卖出/持有。纯推流不产生决策，因此累计值保持 1.00 属正常现象。

### 4.3 曲线本身

| 项目 | 说明 |
| --- | --- |
| 实线 | 累计 calmness |
| 虚线 | 近 10 次滚动冷静度 |
| 背景色带 | 按状态族着色的连续区间（绿/橙/红/灰） |
| ✕ 标记 | 冲动操作决策点 |
| ○ 标记 | 冷静操作决策点 |
| **量程切换** | 右侧 chip「近 120」/「全部」，控制横轴取最近 N 点还是全部历史（上限 1500 点） |
| **查看单点（十字线）** | 鼠标悬停或手指按在曲线上：出现竖直参考线 + 圆点 + 浮动提示框（时间、状态、累计值、滚动值、是否冲动）；移开自动隐藏 |
| **刷新** | 每帧重绘；窗口 resize 自动按 devicePixelRatio 重采样；无数据时显示「暂无数据 · 点击『开始推流』后曲线实时绘制」 |

### 4.4 底部入口

| 按钮 | 作用 |
| --- | --- |
| **图例 / A·B 对照 →** | 打开「详情」抽屉查看完整图例与 A/B 分段对照 |

## 5. 主界面区块三：提醒中心（精简版）

### 5.1 区块作用

集中展示**输出层实际发出的提醒**，是「说了什么话、什么时候说的」的流水账。主界面只放**最新 5 条**，完整列表在同属详情面板。

### 5.2 数据逐项

| 显示元素 | 含义 | 单位 | 更新方式 |
| --- | --- | --- | --- |
| 计数（右上） | 提醒事件**总条数**（不随筛选变化） | 条 | 每新增一条 +1；「重置」后归零 |
| 筛选 chip | 全部 / mild / calm / silent 四选一 | — | 点击即时生效；**主界面与详情 list 共用同一筛选状态** |
| 每条提醒 | 图标、状态中文名、级别徽章、`t=xxx s`、话术正文、`state=… · conf=…` | 时间为仿真秒 | 每新增事件实时插入（带滑入动画） |
| 左侧色条 | 按级别着色：mild 橙、calm 蓝、strong 红、silent 灰 | — | 随级别变化 |

### 5.3 进出过滤规则（口径）

| 规则 | 说明 |
| --- | --- |
| 只收非 silent | `silent` 级不打扰用户，不进入提醒中心 |
| 过滤噪声 | 「冷却中」「弱判别，仅记录状态」「数据不足」被判为噪声，不计入用户可见提醒 |
| 系统消息 | 演示工具、优先级重排提示、稍后提醒等标记「系统」，图标为 🔀 |
| 上限 | 内存保留 200 条，主界面渲染最新 5 条 |

### 5.4 底部入口

| 按钮 | 作用 |
| --- | --- |
| **全部提醒 / 决策模拟 →** | 打开「详情」抽屉：完整提醒列表 + A/B 段 + 决策按钮 |

## 12. 常见问题与边界行为

| 现象 | 原因 / 处理 |
| --- | --- |
| 抽屉关不掉（已修复） | 根因：`.drawer{display:flex}` 类选择器盖掉浏览器 `[hidden]{display:none}`。已在 CSS 加全局 `[hidden]{display:none!important}` 兜底，现支持 ✕ / 遮罩 / ESC 三种关闭 |
| 关闭抽屉后主界面空白？ | 不会。关闭只做显隐切换，并主动重绘一次核心数据；引擎、历史、提醒均不动 |
| 累计冷静度一直是 1.00 | 尚未进行任何「决策」（详情面板的买入/卖出/持有）。推流本身不产生决策 |
| 疲劳状态迟迟不出现 | I_f 半衰期 300s，自然累积约需 10 分钟；打开「设置 → 演示加速」或用「I_f 快进」 |
| 压力状态要等很久 | RR 窗为 60s 时间戳滑窗，窗口换完才会出现 RMSSD 骤降，属真实管道时延 |
| 一直显示「中性/未确认」 | 5s 时间窗内命中率未达 0.6，被时间确认否决；可调低 HIT_RATIO 或缩短 DEBOUNCE_S 观察 |
| 语音播报没声音 | 需开启语音开关 + 勾选对应级别 + 浏览器要求先有用户交互 + 系统有声卡可用；silent 级永不播报 |
| 桌面通知无效 | `file://` 下多数浏览器不支持；改用本地 http 服务打开 |
| 粘贴数据后没开始播放 | 校验未通过（看下方提示的行号错误）；修正后重新点「载入并逐帧播放」 |
| 优先级拖不动 | 请用按住拖拽或 ↑↓ 键；拖拽期间会生成半透明克隆体，松手后自动清理 |
