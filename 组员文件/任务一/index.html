      运用的模型

      • 可解释线性加权判别模型：8 状态各一条 score = Σ wᵢ·z(特征ᵢ)，刻意不用 NN/GBDT 黑盒，保证每条规则可溯源到文献。
      • 个体 z-score 偏离模型：全特征相对校准基线 μ/σ 判偏离，不做绝对阈值；含 σ_min 下限保护。
      • 门控 + 优先级仲裁 + 时间确认：门控定资格，优先级定胜负（stress > anxiety > drowsy > fatigue > distracted > flow > focus > relaxed），5s 窗命中率 ≥0.6 抑制抖动。
      • 信号模型：EWMA 平滑（α=0.2）、伪迹 8×/15× 门限、10s EEG / 60s RR / 30s GYRO 时间戳滑动窗、RMSSD 双指标、I_f 疲劳积分（τ=300 收敛）。
      • 置信度：线性映射 + clamp [0.6, 0.95]；疲劳动/嗜睡走门控余量特判。
      • 干预依据：Laborde 2022 深呼吸放松训练（stress/anxiety 话术）。

      运用的应用 / 接口

      • BrainLink 单通道额区干电极 EEG（设备层）：原始频段功率 + attention/meditation 官方指数。
      • Web Speech API（speechSynthesis）：calm 类话术语音播报。
      • Notification API：桌面系统通知角标提醒。
      • localStorage：偏好本地持久化（隐私模式不可用会自动降级）。
      • Vibration API：移动端 calm 级提醒的短振动反馈。

      运用的软件 / 技术栈

      • Python 3：组长侧参考实现 state_engine.py（v2.8）、brain_sim_tb.py（mock 数据源）。
      • HTML5 + CSS3 + ES2017 JavaScript：本界面，零第三方依赖，可直接双击打开。
      • Canvas 2D：理智度曲线与状态着色带绘制（含 devicePixelRatio 高清重采样）。
      • SVG：置信度环形进度。
      • Pointer Events / Drag & Drop：优先级列表拖拽排序、弹窗拖动、滑杆与曲线十字线。
      • CSS Grid / Flex + 媒体查询：桌面三栏 → 平板两栏 → 移动单栏响应式。

      口径与免责

      • 派生指标（同步率 sync_ratio）为工程派生口径，官方无独立字段。
      • 疲劳/I_f 积分、ADAPT_*、SLEEP_MIGRATE_S 为经验初值，非文献值。
      • F1=89% 系 EPOCX 14 通道被试内结果，单通道额区不可复现。
      • mock 数据仅验证管道与界面，不验证判别准确性。
