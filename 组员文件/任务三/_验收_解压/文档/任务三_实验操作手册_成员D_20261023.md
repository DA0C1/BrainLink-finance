# 任务三 · 实验操作手册

> 负责人：成员 D｜日期：2026-10-23
> 适用：研究者 / 主试

## 0. 一页速查

| 要做的事 | 操作 |
|---|---|
| 启动平台 | `python 盯盘任务_成员D_20261023.py`，浏览器自动打开 |
| 研究者入口 | `/research`，口令默认 `research-demo-token` |
| 建两轮实验 | 填编号 → 选顺序 → “一键两轮（同种子）” |
| 给受试者 | 发 `/s/{6位会话码}` |
| 看实时状态 | 列表点“查看”，指标与曲线实时更新 |
| 导出数据 | 详情右上“导出数据”，得到 zip |
| 对外演示 | 首页“进入 3 分钟演示” |

## 1. 实验前准备

1. 确认 Python 3.13 与依赖已装：
   ```powershell
   cd 项目文件\盯盘实验平台_成员D_20261023
   python -m pip install -r requirements.txt
   ```
2. 设置研究者口令（建议正式实验改默认值）：
   ```powershell
   $env:WATCHLAB_RESEARCH_TOKEN = "你的口令"
   ```
3. 启动：
   ```powershell
   python ..\盯盘任务_成员D_20261023.py
   ```
4. 打开 `/research`，输入口令，点“保存并连接”，看到“已连接”。

## 2. 建会话

页面顶部有一条三步说明：**新建实验 → 发给受试者 → 看数据、导出**。日常只需要第 1 步。

**推荐：一键建两轮（同种子）**

1. 填写受试者编号（如 `S01`）。
2. 点“一键建两轮（推荐）”。页面返回两个 6 位会话码，种子相同；两轮谁先谁后由系统随机分配（符合 T2 随机化方案）。
3. 其余参数保持默认，不用管：单轮 600 秒、每 2000ms 一个点（2 秒一个点）、引擎 Mock。这些放在“高级设置（一般不用改）”折叠区里，除非主试有特殊安排，不要展开修改。

**单轮**：只跑一轮时点“只建这一轮”，其余相同。

> 注意：把 tick 改小于 2000ms 会进入“测试模式”，界面出现黄色水印，**不得用于正式受试者**。

## 3. 受试者进场

1. 把第一个会话的链接 `/s/{会话码}` 发给受试者（同机可复制到浏览器）。
2. 受试者阅读任务说明，勾选知情同意，点“进入实验”。
3. 主试确认：受试者坐姿稳定、未切换窗口、音量可用（有反馈轮需要语音）。
4. 受试者点“开始盯盘”→ 3 秒倒计时 → 开始计时。
5. 本轮结束后页面显示“本轮完成”，请受试者举手。

两轮之间休息 3~5 分钟，再发第二个会话码。

## 4. 监看

研究者在列表点该会话“查看”：

- 5 个指标卡（括号内是给非技术同事的白话解释）：
  - 下单次数（受试者一共买卖了几次）
  - 冷静度（越高越好，冲动下单越少）
  - 专注时间占比（盯盘时保持专注的比例）
  - 系统提醒次数（有反馈轮给了几次提醒）
  - 提醒起效率（提醒后状态变好的比例）
- 每个指标卡下方都有一行灰字说明，汇报时直接照着念即可；
- 价格图：事件竖线、买卖点（冲动决策为红色）；
- 决策记录：tick、方向、仓位、成交价、状态、置信度、是否冲动、归因事件；
- 事件与状态提醒：弹窗与提醒逐条列出。

无反馈轮不应出现“状态提醒”行；若出现，立即记录并停止该轮，检查会话条件是否选错。

## 5. 结束与导出

1. 状态变为“已结束”后，详情右上点“导出数据”。
2. 得到 `watchlab_{session_id}.zip`，内含：
   `prices.csv / decisions.csv / events.csv / states.csv / interventions.csv / session.json`。
3. 建议按 `受试者编号_轮次_日期` 重命名归档，例如 `S01_无反馈_20261023.zip`。
4. 两轮都导出后，用同一份表格做配对比较。

## 6. 常见故障

| 现象 | 处理 |
|---|---|
| 提示“会话不存在或服务已重启” | 服务重启会清空内存会话；重新创建会话 |
| 口令无效 | 检查启动时的 `WATCHLAB_RESEARCH_TOKEN` |
| 页面一直“连接中断，重连中” | 检查服务是否在运行；刷新页面会从快照恢复 |
| 买入提示“可用现金不足” | 仓位过大；改小仓位或先卖出 |
| 卖出提示“当前没有可卖持仓” | 尚未买入；先买入再卖 |
| 有反馈轮没有语音 | 浏览器需先有一次点击；确认系统音量与中文语音包 |
| 想复现同一行情 | 用相同 `seed` 建会话；两轮同种子价格逐点一致 |
