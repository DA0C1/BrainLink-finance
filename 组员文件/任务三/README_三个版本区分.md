> 2026-10-23 · 组长 E

本目录下有三个内容相近的东西，用错会丢修复。**先看这张表，再决定用哪个。**

| 路径 | 是什么 | 什么时候用 |
|---|---|---|
| `_验收_解压/` | **现行运行版**：组员 10-22 交付 + 10-23 组长代改 + 验收数据归档 | 本地运行、答辩演示、继续开发 |
| `盯盘任务_成员D_20261023_交付_含组长代改_20261023.zip` | **现行发布包**（35 项） | 对外分发、拷给别的机器 |
| `盯盘任务_成员D_20261023_交付.zip` | 组员 10-22 原始交付（34 项） | **仅作验收证据**，不要运行 |

## 两个 zip 差在哪

逐项比对：28 项相同，6 项更新，1 项新增。

| 更新文件 | 改了什么 | 为什么必须带 |
|---|---|---|
| `backend/session.py` | 移除下发给受试者端的 `feedback_enabled`；新增 `created_at/finished_at`；metrics 扣 neutral | 属**盲法泄漏**修复：实验条件字段出现在受试者可访问的快照里，DevTools 一看即破盲 |
| `backend/main.py` | 研究者口令改恒定时间比较 + 未注入环境变量时告警 | 原实现有计时侧信道；且默认口令上线无任何提示 |
| `backend/config.py` | 冲动状态补 `distracted`（与 `output_demo.py`/`engine.js` 对齐）；新增会话保留时长常量 | 口径不一致会导致"同样的状态，平台和演示判得不一样" |
| `backend/storage.py` | 未注册会话的日志丢弃改为打警告 | 原实现静默丢日志，事后无法判断是没数据还是丢数据 |
| `frontend/assets/researcher.js` | 专注占比剔除 neutral；响应率要求 ≥5s 连续改善段 | 与任务二定稿口径对齐，否则研究者看到的数和报告里的数不一样 |
| `verify_e2e.py` | 禁发字段补 `feedback_enabled`/`n_ticks`；新增 session 块**白名单**校验 | 黑名单只能挡想到的字段，白名单让"新增字段必须复核"成为默认 |
| `data/README_数据目录说明.md` | 新增 | 说明 CSV 字段、BOM 坑、归档原因 |

## 运行方式

```bash
# 便携运行时（推荐，与主链路同一套，无需装任何东西）
runtime\python\python.exe "组员文件\任务三\_验收_解压\盯盘任务_成员D_20261023.py"

# 已有系统 Python 环境时
python "组员文件\任务三\_验收_解压\盯盘任务_成员D_20261023.py" --port 8080
```

默认 `127.0.0.1:8000`，自动开浏览器。研究者口令：未设 `WATCHLAB_RESEARCH_TOKEN` 时为内置默认值（仅限本地演示）。

`data/` 目录删掉不影响启动——`SessionStore` 会自动重建目录与表结构。
