## 3. 已定事实与决议（方案的地基，不可推翻）

1. **映射表主口径**：HRV/RR → 压力放松（Zou 2018 / Goessl 2017 / Laborde 2022 三条 Meta + Engert 2016，均 Ⅰ 级）；额区 α 相对升降 ↔ 放松/注意投入（Cahn & Polich 2006、Park 2026、Klimesch 2012）；额区 θ 上升 ↔ 觉醒期疲劳（Tran 2020、Wascher 2014、Boksem 2005）。
2. **M13 决议**：专注度主口径 = **θ/β 比值**（θ/β↓ = 专注↑），α↓/β↑ 仅交叉佐证；否决"α↓ 单口径"与"β 绝对功率"。
3. **θ 方向状态依赖**：觉醒疲劳时额区 θ 上升（补偿性执行控制）；嗜睡时 θ/α 反而下降、δ 上升。判读须先用行为/场景区分疲劳与嗜睡。

## 4. 当前建模方案（现状）

### 4.1 算法总框架

```
原始帧(1.2-1.5s/帧) → ① 伪迹剔除+EWMA平滑 → ② 特征计算(滑动窗) → ③ 状态判别(规则+置信度) → ④ 反馈动作
```

### 4.2 预处理参数

| 参数 | 取值 | 依据 | 风险 |
|---|---|---|---|
| EWMA 系数 α | 0.2 | SDK 指南 4.2 推荐 0.1–0.3 | 需实测调参 |
| 伪迹门限 | 单帧比值偏差 > 8 倍平滑值 | 模拟实测经验值（20s 捕获 3 帧突发） | 真机量纲可能不同 |

### 4.3 特征计算

| 特征 | 公式 | 窗口 |
|---|---|---|
| 专注比值 | R_tb = θ/β（同帧） | 窗均值 10s |
| 辅助比值 | R_ba = β/(θ+α) | 同窗 |
| α 相对变化 | A_rel = (ᾱ − α_baseline)/α_baseline | 30s 基线均值 |
| 心率 | HR = 60000/RR_mean | 30s 窗 |
| HRV 时域 | RMSSD = √(mean(ΔRR²)) | 30–60s 窗 |
| 变化速率 | dRMSSD/dt、dHR/dt | 30s 一阶差分 |
| 疲劳积分 | I_f = Σ max(θ_norm − 1.0, 0) × Δt | 全程累积 |

### 4.4 状态判别规则（7 状态）

```
专注:      R_tb < 0.85 × R_baseline        持续 ≥10s      → 专注（置信度 0.8）
分心:      R_tb > 1.15 × R_baseline 且 A_rel > +0.10      → 分心（要求任务中）
放松:      A_rel > +0.10 且 RMSSD > 1.1 × RMSSD_baseline  → 放松
压力:      RMSSD < 0.85 × 基线  且 HR 升 > +8 bpm         → 压力（缓慢态，分钟级）
恐慌:      dRMSSD/30s < −30%    且 dHR/30s > +15%         → 恐慌（速率触发，30s 级）
过度兴奋:  β 激增 > 基线 +2σ     且 HR > 1.15 × 基线      且 形态=突发后平台 → 过度兴奋
疲劳:      I_f > 阈值(个体校准)  且 专注评分持续下滑        → 疲劳
防抖:      任何状态需持续 ≥5s 才切换，避免闪烁
```

### 4.5 反馈与提醒策略

| 状态 | 提醒等级 | 反馈动作 | 依据 |
|---|---|---|---|
| 专注 | 静默 | 无干预 | 最小干预原则 |
| 分心 | 温和 | "回到任务"提示 + 关键信息回顾 | Klimesch 2012 |

### 4.6 理智度量化指标

- 决策冷静度 = 1 − (冲动触发次数/总决策次数)，冲动 = 恐慌/兴奋状态下的操作
