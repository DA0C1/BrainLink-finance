## 二、综述检索 5 步操作

### 第 1 步：去哪搜

- **首选 Google Scholar**（https://scholar.google.com）：快、全，直接搜标题即可看到综述。
- 备用：PubMed（https://pubmed.ncbi.nlm.nih.gov/）、百度学术。
- 校园网环境可上 ScienceDirect、IEEE Xplore 下全文（综述大多在爱思唯尔系期刊）。

### 第 2 步：检索式（直接复制用）

```
EEG emotion recognition review
EEG attention theta beta ratio review
脑电 情绪识别 综述
```

（如结果太多，可加 `meta-analysis` / `systematic review` 限定。）

### 第 3 步：识别综述

标题带以下关键词之一即为综述：**Review / Survey / Scoping Review / 研究进展 / 综述**。优先选 3 年内的。

### 第 4 步：只读 4 处（别全文啃）

1. **摘要**（Abstract）：判断是否相关；
2. **结论**（Conclusion）：记结论；
3. **汇总表**（Tables）：很多综述有"研究汇总表"，直接抄证据；
4. **参考文献**：滚雪球挑原始文献，转给对应维度组员。

### 第 5 步：按阅读卡模板记录

- 用工具包 2.2 表格填写；
- **类型标"综述"**（在"实验范式"栏写"综述/Meta 分析"，"被试数量"栏写"纳入 N 项研究，共 X 人"）；
- 证据强度：系统综述/Meta 分析 → Ⅰ。

## 四、关键结论速记

| 频段/指标 | 对应状态 | 备注 |
|---|---|---|
| α 波 | 放松 / 冥想 | α 增强→放松 |
| β 波 | 专注 / 压力 / 警觉 | β 增强→警觉或紧张 |
| θ 波 | 记忆 / 困倦 | 清醒困倦时 θ 也会上升 |
| δ 波 | 深睡 / 疲劳 | 清醒时高 δ 提示疲劳 |
| γ 波 | 认知加工 / 情绪唤醒 | 与高级认知相关 |
| θ/β 比值 | 注意状态 | **比值升高→注意力涣散、困倦；降低→警觉、专注** |
| 心率变异性（HRV） | 情绪 / 压力 | 与压力、情绪调节相关 |

> 这条速记直接对应《映射关系表》6 个维度的"对应状态"列，汇总时可直接引用。
