## 二、调用方式（三步 HTTP）

ComfyUI 没有"一次调用出图"的接口，是**提交 → 轮询 → 取图**：

```python
# 1) 提交（返回 prompt_id）
POST /prompt
{"prompt": {节点图}, "client_id": "<uuid4>"}
→ {"prompt_id": "5e7781b2-...", "number": 3, "node_errors": {}}

# 2) 轮询（任务完成才会出现该 key；顺便可看 /queue 判断是"排队"还是"卡住"）
GET /history/{prompt_id}
→ {"5e7781b2-...": {"outputs": {"10": {"images": [{"filename": "ui_empty_remind_0007_.png",
                                                  "subfolder": "", "type": "output"}]}}}}

# 3) 取图（二进制）
GET /view?filename=ui_empty_remind_0007_.png&subfolder=&type=output
```

`gen_ui_assets.py` 把这三步封装成 `generate()`，并带 600s 超时、每 12s 打印队列状态（运行/排队），
避免"到底是在算还是在卡"分不清。

## 四、尺寸约定

生成分辨率按「**显示尺寸 × 3~5**」取，且 **64 的倍数**（Qwen/SD3 latent 下采样 8，实践取 64 对齐）：

| 用途 | 生成尺寸 | 显示尺寸 | 倍率 | 依据 |
|---|---|---|---|---|
| 空态插图（卡片内） | **768×768** | 160×160 | 4.8× | 2× 屏足够；再大只增体积 |
| 空态插图（抽屉内） | 同上 | 112×112 | 6.9× | 复用同一文件，不另生成 |
| 横幅 / 说明页头图 | 1024×576（16:9） | 全宽 | 2× | 按容器宽度定 |
| 图标 / 徽标 | 512×512 | 32–64 | 8× | 图标缩小后细节会糊，宁大勿小 |

**不要**生成后再用 CSS 放大（会糊）；也不要为每个显示尺寸单独生成（浪费且构图会变）。

## 五、风格约定（写进 prompt 的固定段）

统一前缀（`STYLE`，已固化在脚本里）：

```
极简矢量线稿插画，单一浅灰蓝色线条，粗细均匀，圆头线帽，大量留白，平面设计，
UI 空状态插图风格，构图居中，主体占画面 55%，四周留空，无文字，无边框，无水印
```

统一负向词（在原有基础上补 UI 相关）：

```
photo, photorealistic, 3d render, text, watermark, signature, logo, frame, border,
blurry, low quality, deformed, colorful paint, oil painting, western art, cartoon,
anime, oversaturated, clutter, gradient background, drop shadow, sticker outline
```

四条硬规则：
1. **单色线稿**，不填充、不渐变、不投影 —— 否则切主题时必翻车
2. **纯色底**，且 prompt 里写明色值（`纯白背景 #FFFFFF` / `深藏青背景 #141D2E`）
3. **无文字/无边框** —— 文字交给 HTML，图里出字必然拼错
4. **留白 ≥ 40%** —— 空态插图要"轻"，塞满会显得像报错

## 六、集成方式（关键：透明化）

模型**给不出精确色值**：深色版实测出的是 `#001520`，而主题 `--surface` 是 `#141D2E`，
直接贴会露出一块深色方框。所以生成后统一做**抠底成 alpha**：

- 背景取 p50 亮度，线色取"离背景更远的那一侧尾部"（p1 或 p99）
- `alpha = |lum - bg| / |line - bg|`，`<0.05` 记为全透明
- RGB 统一设为设计线色，消除抗锯齿带来的偏色

产物：`组员文件/任务一/assets/empty-remind-{light,dark}.png`（14 KB / 17 KB，透明）

接入（`css/styles.css`）：

```css
.empty-slot .es-art {
  display: block; width: 160px; height: 160px;
  background: url(../assets/empty-remind-light.png) center / contain no-repeat;
}
[data-theme="dark"] .empty-slot .es-art {
  background-image: url(../assets/empty-remind-dark.png);
}
```

HTML/JS 侧只放一个装饰性空元素（`aria-hidden="true"`），文案仍是真文本：

```html
<span class="es-art" aria-hidden="true"></span><b>暂无提醒事件</b>
```

⚠ 注意：`EMPTY_SLOT` 在 `app.js` 里还有一份（动态渲染用），**改结构要两处一起改**，
否则首次渲染是图、重渲染变回 emoji —— 这个坑本轮踩过。

## 七、复现与扩展

```bash
cd 项目文件

python gen_ui_assets.py --list                    # 看资产清单
python gen_ui_assets.py --dry-run --only xxx      # 只校验参数，不生成
python gen_ui_assets.py --only empty-remind-light # 生成单张（首次约 48s，之后 ~24s）
python gen_ui_assets.py                           # 全部生成
python gen_ui_assets.py --post                    # 只重做抠底（换线色时用）
```

新增一张资产 = 在 `ASSETS` 里加一条（name / 尺寸 / seed / 背景描述 / 画面描述 / 文件名），
跑 `--only` 生成 → `--post` 抠底 → 在 CSS 里加一条 `background`。

`assets/manifest.json` 记录每张图的 prompt、负向词、seed、尺寸、模型、`sha256` 与
抠底后的覆盖率，审计/复现都靠它。

## 八、本轮踩到的四个坑（都已在脚本里固化）

| # | 坑 | 现象 | 处置 |
|---|---|---|---|
| 1 | 工作流不在 `workflows/` | 目录里只有音频/视频流 | 从 PNG 的 `tEXt.prompt` 里读（见 §一） |
| 2 | 背景色不可控 | 要 `#141D2E`，给 `#001520` | 抠成 alpha，不依赖底色 |
| 3 | alpha 基准用 min/max | 浅色图线芯只到 83% 不透明，整张发灰（431 个实心像素） | 改分位数基准（→ 6991 个实心像素） |
| 4 | 只改 HTML 没改 JS 常量 | 刷新后插图变回 🔔 | `EMPTY_SLOT` 两处同步 |
