## 三、阅读卡（综述/数据集类，共 6 张）

### 卡 1 · 脑电情绪识别综述

| 字段 | 内容 |
|---|---|
| 文献信息 | Rahman MM et al., 2021, Recognition of human emotions using EEG signals: A review, Computers in Biology and Medicine, 136:104696；DOI 10.1016/j.compbiomed.2021.104696（PMID 34388471） |
| 数据维度 | 多维度混合（情绪识别涉及的 α/β/θ/γ 频段特征） |
| 实验范式 | **综述**（情绪诱发的 EEG 研究汇总：特征提取—特征选择—分类全流程） |
| 被试数量 | 综述型，汇总多篇实验研究，未统一报告总 N |
| 核心结论 | 情绪可通过 EEG 信号分类识别，EEG 相比其他生理信号获取简便、被试接受度高；系统梳理了时域/频域/时频特征、特征选择与分类器（SVM、ANN、深度学习等）的主流方法；情绪与脑活动的频段关联（含额区不对称等）是识别理论基础 |
| 证据强度 | Ⅰ（同行评议期刊综述） |
| 与 BrainLink 可比性备注 | 综述所涉研究以多通道（多为 14–64 通道）湿电极实验室设备为主；BrainLink 为单通道额区干电极，可提取 α/β 等频段功率，但空间定位与通道数量不可直接画等号；该综述本身不涉及消费级设备 |

### 卡 2 · EEG 指标↔情感/认知模型映射综述（核心参考）

| 字段 | 内容 |
|---|---|
| 文献信息 | Gkintoni E, Halkiopoulos C, 2025, Mapping EEG Metrics to Human Affective and Cognitive Models: An Interdisciplinary Scoping Review from a Cognitive Neuroscience Perspective, Biomimetics (Basel), 10(11):730；DOI 10.3390/biomimetics10110730（PMID 41294401） |
| 数据维度 | 多维度混合（额区 α 不对称、θ、β、γ、θ/β 比值） |
| 实验范式 | **综述/Meta 分析**（跨学科范围综述：实验室 + 自然场景 EEG 研究） |
| 被试数量 | 范围综述，跨多篇研究 |
| 核心结论 | 额区 α 不对称（8–13 Hz）可靠编码情绪效价，分类准确率 75–85%；唤醒度与广泛 β/γ 功率变化相关；额-中线 θ（4–8 Hz）随工作记忆负荷线性上升；α 抑制标记注意投入；θ/β 比值是稳健的认知负荷/注意状态指标；ML 状态分类准确率 70–95% |
| 证据强度 | Ⅰ（同行评议期刊范围综述） |
| 与 BrainLink 可比性备注 | 关键指标（θ/β 比值、额区 α/β 功率）均可由单通道额区设备计算，BrainLink「专注度/放松度」字段即基于此类频段功率构建，**口径可类比、绝对数值不可直接外推**；该文涉及 Fz 等额区导联，为多通道研究为主 |

### 卡 3 · EEG 认知绩效指标系统综述

| 字段 | 内容 |
|---|---|
| 文献信息 | Ismail LE, Karwowski W, 2020, Applications of EEG indices for the quantification of human cognitive performance: A systematic review and bibliometric analysis, PLoS One, 15(12):e0242857；DOI 10.1371/journal.pone.0242857（PMID 33275632） |
| 数据维度 | 多维度混合（θ/α/β 功率、PSD、ERP；精神疲劳、心理负荷、心理努力、压力） |

## 五、底稿小结（对周末「三件套」的初步贡献）

1. **综述层证据方向与速记表一致**：α 增强→放松（额区 α 不对称编码效价，75–85%）；β/γ 功率→唤醒/警觉；额区 θ→负荷/记忆；θ/β 比值升高→注意涣散、降低→警觉专注；δ 与 HRV 两行本批综述覆盖较弱，需靠 A–D 原始证据补足。
2. **初步建议标「可支撑模拟程序假设」的行**：α–放松、θ/β–注意状态、θ–认知负荷/疲劳（碰头会逐条确认）；**仅作探索**：δ–深睡、γ–高级认知、HRV–压力（证据尚需 A–D 补充）。
3. **设备边界论证素材**：卡 2、卡 6 可支撑「单通道额区干电极可计算频段功率与比值，但绝对数值与空间定位不可与多通道湿电极直接画等号」的表述。
