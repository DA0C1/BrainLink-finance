### δ 波维度（4 张）

**卡 D1 · 清醒态 δ 的认知功能综述**

| 字段 | 内容 |
|---|---|
| 文献信息 | Harmony T., 2013, The functional significance of delta oscillations in cognitive processing, Frontiers in Integrative Neuroscience, 7:83；DOI 10.3389/fnint.2013.00083 |
| 数据维度 | δ（0.5–3.5 Hz，1–3.9 Hz） |
| 实验范式 | **综述**（汇总清醒认知任务中的 δ 振荡：心算、语义任务、Sternberg 工作记忆、Go/No-Go） |
| 被试数量 | 综述型，汇总多篇实验 |
| 核心结论 | 清醒专注状态下 δ（尤其额区）功率升高主要见于内指向/集中注意任务（心算、Sternberg 工作记忆、No-Go 抑制）；提出 δ 振荡可能通过抑制与任务无关的感觉传入网络来服务内部集中；**δ 不只见于睡眠，清醒内指向注意中额区 δ 同样升高** |
| 证据强度 | Ⅱ（同行评议叙述性综述，非系统综述） |
| 与 BrainLink 可比性备注 | 多为实验室多通道、额区导联为主；BrainLink 单通道额区正好落在 δ 被报告的额区位置，**口径可比**；但综述所指为「内指向注意/抑制」而非「疲劳嗜睡」，方向上与「高 δ=嗜睡」存在张力，需在映射表标注 |

**卡 D2 · 慢波（δ）作为睡眠稳态/恢复指标的大样本对照**

| 字段 | 内容 |
|---|---|
| 文献信息 | Van Dongen HPA, Maislin G, Mullington JM, Dinges DF., 2003, The Cumulative Cost of Additional Wakefulness: Dose-Response Effects on Neurobehavioral Functions and Sleep Physiology From Chronic Sleep Restriction and Total Sleep Deprivation, SLEEP, 26(2):117–126；DOI 10.1093/sleep/26.2.117 |
| 数据维度 | δ（NREM 睡眠 δ 功率） |
| 实验范式 | **剂量-反应对照实验**（随机分 4h/6h/8h 限睡 14 天，另设 0h 全 deprivation 3 晚；多导睡眠图） |
| 被试数量 | N=48 健康成人（21–38 岁） |
| 核心结论 | NREM 睡眠 δ 功率是公认的睡眠稳态指标，对限睡呈急性反应；全 deprivation 引起的清醒神经行为损害与睡眠 δ 反应远大于同等睡眠丢失的慢性限睡；清醒超过约 15.84 h 后行为警觉失误近线性累积；**长期清醒累积的「睡眠债」主要体现在恢复睡眠中 δ 反弹** |
| 证据强度 | Ⅱ（N=48 大样本对照，接近 50；领域经典） |
| 与 BrainLink 可比性备注 | δ 结论来自夜间 NREM 多导睡眠，BrainLink 为清醒态额区采集，**睡眠 δ 不可直接等同于清醒 δ**；但「清醒越久、恢复需求越高（以 δ 为代理）」这一机理方向可支撑「δ 升高≈疲劳/恢复需求上升」的项目假设 |

**卡 D3 · 清醒嗜睡期的局灶 δ 岛（颅内 ECoG）**

| 字段 | 内容 |
|---|---|
| 文献信息 | Slater JD, Chelaru MI, Hansen BJ, Beaman C, Kalamangalam G, Tandon N, Dragoi V., 2017, Focal Changes to Human Electrocorticography With Drowsiness: A Novel Measure of Local Sleep, Journal of Neuropsychiatry and Clinical Neurosciences, 29(3):236–247；DOI 10.1176/appi.neuropsych.16060120（PMID 28121257；期刊勘误：非 J Clin Neurophysiol） |
| 数据维度 | δ（局灶功率） |
| 实验范式 | **颅内电极（ECoG）观察性研究**（难治性癫痫患者视频-ECoG 监测，清醒随时间推移进入嗜睡） |
| 被试数量 | N=6 患者 |
| 核心结论 | 清醒嗜睡过程中出现「局灶性 δ 功率升高岛」并伴随局部神经元活动下降（局灶皮层不活动）；随清醒时间延长，「不活动电极」数量进行性增多；**证明清醒态下 δ 局灶升高是嗜睡/局部睡眠的标志** |
| 证据强度 | Ⅲ（N=6，颅内电极患者样本，非健康成人） |
| 与 BrainLink 可比性备注 | 侵入式 ECoG、样本为癫痫患者，外推到健康消费级设备受限；但「清醒 δ 升高=嗜睡局部睡眠」方向明确，可作机理支撑，须在映射表标注为低强度证据 |

**卡 D4 · 疲劳模拟驾驶中频段变化（含 δ 阴性结果，作张力证据）**

| 字段 | 内容 |
|---|---|
| 文献信息 | Craig A, Tran Y, Wijesuriya N, Nguyen H., 2012, Regional brain wave activity changes associated with fatigue, Psychophysiology, 49(4):574–582；DOI 10.1111/j.1469-8986.2011.01329.x（页码勘误：非 544–552） |
| 数据维度 | θ、α1/α2、δ、β（全皮层慢波/快波） |
| 实验范式 | **对照实验**（非职业健康驾驶员模拟驾驶至疲劳） |
| 被试数量 | N=48 |
| 核心结论 | 随疲劳进展，**全皮层慢波活动（θ 与 α1/α2）升高，而 δ 活动无显著变化**；快波（尤其额区 β）显著升高；解释为脑「失能变慢」同时「努力维持警觉」导致 β 升高。**即清醒疲劳中升高的是 θ/α 慢波而非 δ** |
| 证据强度 | Ⅱ（N=48 实验室对照） |
| 与 BrainLink 可比性备注 | 多通道实验室设备；该文给出与「高 δ=疲劳」相反的**阴性结果**——清醒任务疲劳时 δ 并未显著升高。必须诚实写入映射表的「矛盾/张力」列：δ 升高更可靠地对应「嗜睡/局部睡眠或夜间恢复」，而非清醒任务疲劳，避免答辩被质疑 |

### HRV 维度（4 张）

**卡 H1 · 身心运动改善 HRV 与主观压力的 Meta 分析**

| 字段 | 内容 |
|---|---|
| 文献信息 | Zou L, Sasaki JE, Wei GX, Huang T, Yeung AS, Neto OB, Chen KW, Hui SS., 2018, Effects of Mind–Body Exercises (Tai Chi/Yoga) on Heart Rate Variability Parameters and Perceived Stress: A Systematic Review with Meta-Analysis of Randomized Controlled Trials, Journal of Clinical Medicine, 7(11):404；DOI 10.3390/jcm7110404（PMID 30384420） |
| 数据维度 | HRV（LFn、HFn、LF/HF 比值）+ 主观压力 |
| 实验范式 | **系统综述 + Meta 分析**（17 项中高质量 RCT） |
| 被试数量 | 纳入 17 项 RCT |
| 核心结论 | 身心运动显著改善 HRV：HFn 升高（Hedges g=0.37）、LF/HF 比值下降（g=−0.58），主观压力显著下降（g=−0.80）；结论指向「减压通过调节交感-迷走平衡实现」，即**HRV（尤其 HF/迷走成分）升高=放松/压力下降** |
| 证据强度 | Ⅰ（RCT 的系统综述/Meta） |
| 与 BrainLink 可比性备注 | 结论基于 ECG 采集的 HRV；BrainLink 输出心率 RR 值可派生基础 HRV 指标，**口径方向一致**；但消费级 RR 序列长度/呼吸控制未标准化，绝对 HF/LF 数值不可与实验室等同 |

**卡 H2 · HRV 生物反馈降低压力与焦虑的 Meta 分析**

| 字段 | 内容 |
|---|---|
| 文献信息 | Goessl VC, Curtiss JE, Hofmann SG., 2017, The effect of heart rate variability biofeedback training on stress and anxiety: a meta-analysis, Psychological Medicine, 47(15):2578–2586；DOI 10.1017/S0033291717001003（原候选 DOI …1763 证伪改正） |
| 数据维度 | HRV + 压力/焦虑自评 |
| 实验范式 | **Meta 分析**（随机效应模型） |
| 被试数量 | 24 项研究，共 484 名接受 HRV 生物反馈者 |
| 核心结论 | HRV 生物反馈训练与自我报告压力、焦虑的大幅下降相关：组内前后效应 Hedges g=0.81，组间对照 g=0.83（大效应）； moderator 分析未发现偏倚、性别、次数等显著调节；**HRV 升高与压力/焦虑下降的关联在干预研究中稳健** |

**卡 H3 · 主动慢呼吸升高迷走 HRV 的大样本 Meta**

| 字段 | 内容 |
|---|---|
| 文献信息 | Laborde S, Allen MS, Borges U, Dosseville F, Hosang TJ, Iskra M, Mosley E, et al., 2022, Effects of voluntary slow breathing on heart rate and heart rate variability: A systematic review and a meta-analysis, Neuroscience and Biobehavioral Reviews, 138:104711；DOI 10.1016/j.neubiorev.2022.104711（PMID 35623448） |

### γ 波维度（3 张）

**卡 G1 · 情绪唤醒的 γ 振荡经典研究**

| 字段 | 内容 |
|---|---|
| 文献信息 | Keil A, Müller MM, Gruber T, Wienbruch C, Stolarova M, Elbert T., 2001, Effects of emotional arousal in the cerebral hemispheres: a study of oscillatory brain activity and event-related potentials, Clinical Neurophysiology, 112(11):2057–2068（PMID 11682344） |
| 数据维度 | γ（30–45 Hz 早中期、46–65 Hz 晚期） |
| 实验范式 | **情绪图片（IAPS）诱发实验**（129 导 EEG） |
| 被试数量 | N=10 健康大学生 |
| 核心结论 | 厌恶（负性）刺激在刺激后约 80 ms 即增强早期中 γ（30–45 Hz）；晚期高 γ（46–65 Hz，约 500 ms）对「唤醒度高」图片（不论效价）强于中性；晚期 γ 呈右侧半球优势；**γ（尤其晚期高 γ）是情绪唤醒皮层网络加工的相关物** |
| 证据强度 | Ⅲ（N=10 小样本，但高被引、领域奠基） |
| 与 BrainLink 可比性备注 | γ（>30 Hz，常到 46–65 Hz）远高于消费级单通道额区设备的有效频带（BrainLink 类设备频段多止于 ~45 Hz 且额区 γ 极弱）；**BrainLink 基本无法可靠捕捉 γ**，此结论仅作机理背景，不能在设备端复现，必须在答辩中明确 |

|---|---|

| 数据维度 | γ + α（后区） |
| 实验范式 | **被动观看情绪图片（IAPS）分块任务** |
| 被试数量 | N=32 |

| 字段 | 内容 |
|---|---|

**缺口如实说明**：
1. **δ 方向存在内部张力**：清醒任务疲劳中 δ 并未显著升高（D4, N=48 反证），高 δ 更可靠对应「嗜睡/局部睡眠或夜间恢复」。建议映射表将 δ 行标为「证据：部分一致/有歧义」，并备注 BrainLink 额区单通道对 δ（尤其慢波）的可测性有限。
2. **γ 维度设备不可复现**：3 条 γ 证据均基于多导/颅内，且 γ 频带超出 BrainLink 有效范围；只能作机理背景，不能写为「设备可测」。
3. **数据集论文未新增**：本轮重点补维度证据，公开数据集仍沿用卡 4 DEAP；若模拟程序需要更多情绪 EEG 公开数据集（如 AMIGOS、SEED/DEAP 扩展），建议下一轮专项补 1–2 篇。
4. **DOI 复核（2026-10-12 已全部解决）**：原 9 条「待复核」已逐条核验补全——Goessl=10.1017/S0033291717001003、Laborde=10.1016/j.neubiorev.2022.104711、Lomas=10.1016/j.neubiorev.2015.09.018、Lagopoulos=10.1089/acm.2009.0113、Mitchell=10.1016/j.pneurobio.2008.09.005、Valentino=10.1016/0167-8760(93)90070-6、Tripathi & Sharma=10.3390/s23073474、Kwak & Grable=10.4309/WZXX6075、Slater=10.1176/appi.neuropsych.16060120（期刊勘误为 J Neuropsychiatry Clin Neurosci 29(3):236-247）；另补 Craig 2012=10.1111/j.1469-8986.2011.01329.x 并勘误页码 574-582。其中 2 条底稿候选 DOI 被证伪（Goessl …1763、Lomas …023），已全部改正；综述报告相应条目已同步修正。正式入库时仍建议在校园网对 PubMed/原期刊页做最后一遍点检。
