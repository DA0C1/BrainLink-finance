# 脑机接口状态判别系统 · 便携版使用说明

> 版本 **v3.16** ｜ 最后更新 2026-11-11
> **一句话**：整个 `脑机接口项目` 文件夹拷到任何 Windows 10/11 64 位机器，双击就能跑。
> 不需要装 Python，不需要装任何第三方包，不需要联网。

**这份文档面向三种人**：① 现场演示/答辩的人（看第一、五节）；② 第一次拿到包的组员（看第二、三、四节）；
③ 想知道这一版改了什么的人（看第六节）。

> 补测数据已经采完并入库（5 份 dump / 1876 帧），**不需要再采集**。
> 若要重新采，用 `启动-数据采集.cmd`；采集协议见 `组员文件/任务一/README.md`。

## 一、演示与汇报：三条路径，按需选一条

| 路径 | 命令 | 适合什么场合 | 能证明什么 / 不能证明什么 |
|---|---|---|---|
| **A 模拟数据** | 双击 `启动-实时面板.cmd` → 选 `1` | 彩排、无硬件的场合、网络答辩 | 能证明**链路通、8 态判别在跑、提醒会触发**；**不能**证明判别准确率（合成数据） |
| **B 回放 CSV** | 双击 `启动-实时面板.cmd` → 选 `3` → 粘贴 CSV 路径 | 现场真机连不上时的兜底；反复演示同一段 | 能证明**完整录制回放链路**；数据来源要在讲解时说明是录制还是合成 |
| **C 真机串口** | 双击 `启动-实时面板.cmd` → 选 `2` → 输入 COM 号 | 正式演示、评委要看真设备 | 能证明**串口 → 浏览器 → 判别**全链路；受试者状态本身另说 |

### 1.1 演示前的 3 分钟检查（照做，别跳）

1. 双击 **`启动-环境自检.cmd`** → 看到「结论：可运行」或「全部通过」。
2. 双击 **`启动-实时面板.cmd`** → 选 `1` → 浏览器自动打开 `http://127.0.0.1:8770/`。
3. 界面上确认三件事：
   - 顶栏模式停在「**自动轮播**」，左卡状态名在变；
   - 中间曲线有折线在走；
   - 左下 8 个状态格子里，被点亮的那格会随时间切换。
4. 点一下右上角「**演示 / 产品**」徽标 —— 演示形态会保留手动注入按钮；产品形态把它们藏起来。
   答辩默认用**演示形态**，讲"产品化"时再切过去。

> 没有浏览器自动打开时，手动访问 `http://127.0.0.1:8770/`。端口被占用会在启动窗口给出提示。

## 二、为什么不需要装 Python

项目根目录里带了完整运行时：

```
runtime/python/python.exe          解释器本体（Python 3.13.15）
runtime/python/Lib/site-packages/  第三方包（仅 pyserial 3.5）
runtime/python/python313._pth      路径配置（关键，见下）
```

这是 Python 官方的 **Embedded 发行版**，解压即用、不写注册表、不改系统环境变量，
删掉文件夹就等于卸载干净。v3.16 把混进来的 numpy/fastapi/pydantic 等无关包清掉了，
运行时从 96 MB 降到 **21 MB**。

`python313._pth` 的内容是：

```
python313.zip
.
../../项目文件
Lib/site-packages
import site
```

其中 `../../项目文件` 是**相对 `python.exe` 的路径**，作用是把项目自己的模块目录加进
`sys.path`——**没有这一行，`import state_engine` 会失败**。嵌入式 Python 有一个容易踩的行为：
一旦存在 `._pth`，它就不再自动把"脚本所在目录"加进 `sys.path`。这是本项目从"能跑"到
"拷走也能跑"之间最关键的一处配置。

## 四、拷到新机器的注意事项

1. **整目录复制，不要只挑子目录**。`runtime/` 和 `项目文件/` 少任何一块都跑不起来。
2. **路径可以有中文和空格**（已实测），但**不要放在需要管理员权限的位置**（如 `C:\Program Files`），
   否则 `项目文件\data\` 写不进去。
3. **U 盘拔插后盘符变了不影响运行**：`._pth` 与启动器的 `%~dp0` 都是相对自身。
4. **杀毒软件**可能对 `python.exe` 首次运行弹窗，允许即可。
5. 目标机器若是 **32 位 Windows 或 ARM**，内置运行时不能直接用，需换对应架构的 Embedded 包
   （其余代码无需改动）。

## 五、常见问题（含演示现场专用）

**Q：双击 .cmd 一闪就没了？**
A：说明提前退出了。在该目录地址栏输入 `cmd` 回车，手动敲 `启动-环境自检.cmd` 看报错。
最常见是 `runtime\python\python.exe` 不存在（复制不完整）。

**Q：提示 port 8770 被占用？**
A：上一次的服务窗口没关。去任务栏找「脑机接口-数据服务」关掉，或改用
`live_bridge.py --port 8771`。

**Q：面板一直是「等待数据」？**
A：先看服务窗口有没有报错。v3.16 起服务端会明确区分三种情况并在界面上挂提示条：
① 数据源已停止（串口名写错 / 被拔掉）→ 红条 +「重新连接」；
② 回放已结束 → 提示可加 `--loop` 循环；
③ 已暂停 → 黄条「数值已冻结」。**不再笼统说"蓝牙卡顿"**。

**Q：真机演示中途头环掉了怎么办？**
A：立刻切到回放（路径 B），用 `demo_mock_8phase.csv` 或本机导出的 `demo_real.csv` 继续，
讲解时说"这是录制回放，用于排除硬件不确定性"。**不要说"刚才是假的"。**

**Q：点「压力」格子为什么十秒后才变？**
A：stress 判据依赖 HRV（RMSSD 的 60 秒滑动窗口）。切换后的头几秒窗口里还是上一段的 RR，
实测约 **8–10 秒**才翻过来。这是设计行为，不是卡住。演示时提前说明，或先讲别的格子。

**Q：点「疲劳」格子为什么没有弹提醒？**
A：疲劳的置信度实测在 **0.61–0.67**，低于弱判别阈值 0.7，系统按设计**只记录不打扰**，
界面上会标「弱判别」。这恰好是可以主动讲的点：*证据不足时系统不装作确定*。
要演示"弹提醒"，用**焦虑 / 嗜睡 / 分心**这三个（conf 0.77–0.95）。

**Q：要不要装官方 BrainLinkParser？**
A：不用，也装不上（不在 PyPI，且只有 Python 3.11 的二进制）。项目自带 `tgam_parser.py`，
覆盖 EEG 全部主干；代价是拿不到 RR / 心率，`stress` 一态在真机上不可判——属于
**硬件通道限制**，界面已用「无 RR」标出。

**Q：能用我自己装的 Python 跑吗？**
A：可以。`python 项目文件\doctor.py` 会提示「解释器来源：系统 Python」，功能一致。
但换机器时需先装 pyserial，所以推荐用内置运行时。

## 六、v3.16 这一版改了什么（相对上一版分发包）

| 类别 | 变化 | 为什么重要 |
|---|---|---|
| **时间戳** | `ts=0` 不再被当成"缺值" | 修复前：从 0 开始的录制会让 10 秒窗永不裁剪，回放退化成全程平均，且缓冲线性增长 |
| **帧源看门狗** | `/health` 返回 `alive` / `error` / `last_frame_ago`；串口名写错启动即报错退出 | 修复前：错 COM 口时服务照跑、界面显示"已连接"却永远没数据 |
| **实时性** | 新 SSE 连接只推实时帧；要历史用 `?backfill=N` | 修复前：新开页面先灌 600 帧（5–10 分钟前的数据） |
| **校准估计量** | band 特征改用 **10 秒窗均值**估 μ/σ，与运行时同一把尺 | 修复前：校准用逐帧、运行时用窗口均值，σ 差 2–3 倍，判据实际灵敏度被压掉 |
| **回放一致性** | 新增 `frameio.py`，两条回放路径共用一份转换 | 修复前：`signal` 缺列一边当 0 一边当 None、`rr_ms` 一边取批首一边取批尾 |
| **安全** | 安全响应头 + CSP、`--token` 保护 `/stream` 与 `/health`、静态路径 `realpath` | 局域网演示时不会被同网段直接读数 |
| **包体** | 33.2 MB → 约 16.5 MB | 运行时裁掉 38 个从未被 import 的包 |
| **演示素材** | 新增 `demo_mock_8phase.csv` + `make_demo_csv.py` | 包内原本没有任何可回放文件，菜单第 3 项是空转 |

完整的数字口径见 `docs/FACTS.md`；改动清单见 `我的文件（组长）/工程审查与优化建议_组长E_20261111.md` §9。
