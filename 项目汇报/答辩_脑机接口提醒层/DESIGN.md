# DESIGN.md — 答辩演示文稿设计规范（v2 · 12 页）

> 场景：高校课程答辩 ｜ 受众：课程教师 + 评审 ｜ 时长 **12 分钟**（讲 11 + 缓冲 1）
> 页数 **12 页** ｜ 风格：学术风（学术宝蓝 + 白底，证据驱动、克制）
> 叙事主线：**做什么 → 为什么难 → 怎么实现 → 做出来什么样 → 做了多少 → 谁做的 → 没做到什么**
> 关键约束：**无彩排** → 不现场操作，界面以实机截图呈现；讲稿写进每页备注，另出分册

## 一、全局视觉约定

### ① 画布与安全区
- 画布 1280×720
- padding：上下 60px / 左右 60px（硬下限）
- 内容区 1160×600
- 页脚落在 y=678 带内；封面不加页脚

### ② 配色方案（学术宝蓝 + 白底）

| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#1E4FA8` | 顶条、编号块、强调线、关键数字 |
| 辅色 | `#3D7BD9` | 描边、图表第二色、次级强调 |
| 浅辅 | `#E8EFF8` | 结论条底、KPI 卡底、表头底 |
| 强调色 | `#D9534F` | **仅**用于"不可判 / 未证明 / 风险"，全篇 ≤3 处 |
| 正文 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助 |
| 底色 | `#FFFFFF` | 主背景（≥60%） |
| 辅底 | `#F7F9FC` | 局部底（不做主底） |
| 线 | `#D6DCE5` / `#E5E7EB` | 分区细线、卡片描边 |

**纪律**：蓝族 20–40%，白底 ≥60%，红 ≤3%，金色 0。

### ③ 字体系统
- 中文：**微软雅黑**；西文/数字：**Arial**
- 字号阶梯：封面主标 44 / 页主标 34 / 卡片小标 21 / 正文 18–20 / 表格 17 / 注释页脚 14 / KPI 巨数字 40

### ④ 视觉母题（全篇复用）
1. **内容页顶条**：高 64px 深蓝实色，左页标题（34px Bold），右 `0N · 英文标识`（16px，白色 70%）
2. **顶条下方信息横幅**：浅蓝底 + 4px 主色竖条，内放本页一句话论断（20px）
3. **页脚**：左"脑机接口数据在金融实践中的应用 · 课程答辩"，右 `0N / 12`（14px 浅灰）
4. **结论条**：页末通栏浅底 + 2px 主色顶线，放本页唯一结论（18–20px）

### ⑤ 图片与素材管线

> **关键结论（v2 实测）**：转换器的 `Image` 组件一律写 1145 字节占位图，PNG/JPG/base64 全失败；
> 但 **`backgroundImage: url(data:image/jpeg;base64,...)` 可用**，位图能正常嵌入 PPTX。
> 因此：界面/平台一律用**实机截图**，分析与示意用 **Box / 内联 SVG 重绘**。

- 源图放 `assets_src/*.jpg`（宽 1000–1120px、q80–90，单张 30–95 KB）
- 模板写占位符 `__IMG_COVER__ / __IMG_MAIN__ / __IMG_WATCHLAB__`
- `build_slides.py` 把占位符替换成 data URI，输出到 `.build/NN.slide`（这才是导入用的文件）
- 改图流程：换 `assets_src` 里的 jpg → `python build_slides.py` → 重新 upsert 该页

| 素材 | 来源 | 署名/说明 |
|---|---|---|
| 封面线稿 | ImageGen 生成（单通道采集 → 状态曲线） | 页面标注「示意图」 |
| 主面板 `ui_main.jpg` | 本项目 v3.16 实机截图（回放模式） | 本项目自有，无需外部署名 |
| 盯盘平台 `watchlab.jpg` | 任务三交付件 `文档/截图3_交易页演示.png` | 平台为组员自制，页脚注明"演示模式" |
| 8 态网格 / 冷静度曲线 | 内联 SVG 重绘（参数与真实面板一致） | 不依赖位图，投影更清晰 |

> 若后续引入**厂商官方图**（如 BrainLink 产品照），必须在该页页脚写明来源与获取日期。

## 三、讲述方式

**五个人接力讲，一人一段**：组长（1–3、5、10–12）· 组员④（4）· 组员①（6–7）· 组员②（8）· 组员③（9）。
组员④ 全程站电脑后侧，负责 P4 真机与 P7 演示；其余人讲完回第一排。

| 段 | 页 | 内容 | 谁 |
|---|---|---|---|
| 前景 | 1–3 | 是什么 · 值得做 · 能做多大 | 组长 |
| 实现 | 4–7 | 系统分三层（真机 10s）· 八态 · 校准与提醒 · 界面（演示 30s） | ④ / 组长 / ① |
| 成果 | 8–11 | 数据方法工程 · 工作量与分工 · 实验平台 · 路线图 | ② / ③ |
| 下一步 | 11 | 路线图与限制 | 组长 |
| 收尾 | 12 | 一句结论 | 组长 |

合计约 21 分钟（含两处演示 40 秒）。时间宽裕，不掐表。

**演示位置**：第 4 页真机 10 秒（④ 自己讲自己切，可选）；第 7 页模拟 30 秒（① 说口令、④ 操作）。
只跑合成数据与回放；失败即退回截图，不现场修。

## 四、制作与校验流程

```bash
python build_slides.py                       # 模板 + 图 → .build/NN.slide
slidep create  xxx.pptx
slidep upsert-dsl xxx.pptx --dsl-file .build/01.slide    # 依序 01→12
slidep lint  xxx.pptx --dsl-file .build/NN.slide         # 逐页零告警
slidep screenshot xxx.pptx --page-index N --out .preview/NN.png
```

**验收线**：12 页 lint 全 `ok:true`；渲染图逐页目检，无裁切、无压字、页脚不撞结论条。
