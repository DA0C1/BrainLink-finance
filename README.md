# BrainLink-finance · 脑机接口数据在金融实践中的应用

用消费级单通道脑电设备（BrainLink Pro / TGAM）判断使用者当前的状态，在**做决策之前**给一句提醒。

> 它不告诉你该买什么，只告诉你现在适不适合做决定。

本项目是课程项目，交付的是一个**能跑通、能复现、能被别人接手**的完整链路：采集 → 判别 → 校准 → 提醒 → 实验验证。不是算法 demo，也不是医疗器械。

---

## 1. 它解决什么问题

交易记录里有时间、价格、数量，没有"下单那一刻我是什么状态"这一列。事后补不回来，靠回忆又会被当下状态带偏。

本系统在决策发生的那一刻，把状态记下来，并在该打断的时候打断一次：

| 场景 | 触发 | 动作 |
|---|---|---|
| 盯盘防疲劳 | 连续专注 40 分钟且判到疲劳 | 提醒起身休息，不介入决策 |
| 下单前自检 | 判到焦虑 | 弹一次二次确认，不拦单，只让人停三秒 |
| 交易复盘 | 每笔交易绑定当时状态 | 一个月后看自己在什么状态下容易做错 |
| 交易室看板 | 多人在岗状态总览 | 风控岗一眼看到谁该换班 |

## 2. 系统分层

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  采集层       │   │  判别层       │   │  呈现层       │
│ serial_bridge│──▶│ state_engine │──▶│ 前端（零依赖） │
│ tgam_parser  │   │ 8 状态+可信度 │   │ 8 格 / 曲线   │
└──────────────┘   └──────────────┘   └──────────────┘
   每秒一条记录：8 个频段 + attention/meditation + 接触质量
```

三层之间只传**一种固定格式的记录**，所以每层可以单独替换、单独测试。

- **采集层**：串口字节流拆包、校验、拼帧；接触不良的特殊值直接丢弃，不参与判断（否则会被当成"特别放松"）。
- **判别层**：五步——取最近一段 → 算特征 → 过八套规则（条件必须同时满足）→ 连续满足才算 → 给 0.60–0.95 的可信度。
- **呈现层**：八个状态格 + 每格可信度条；判不了显示"—"而不是 0 分；四级提醒（只记录 / 记一条 / 弹一句 / 加重）。

### 八个状态 + neutral

专注 · 分心 · 放松 · 焦虑 · 心流 · 嗜睡 · 疲劳 · 压力，之外还有一个 `neutral`（"说不清"，约占 1/4 时间）。

规则来源分三档，不混着说：

| 档 | 状态 | 依据 |
|---|---|---|
| A | 压力 | 文献有具体阈值（HRV / RMSSD） |
| B | 专注、分心、放松、嗜睡 | 文献只有方向共识，门限自定 |
| C | 焦虑、疲劳、心流 | 工程自定规则，只说"与该状态一致的模式" |

## 4. 怎么跑

### 方式一：便携包（推荐给非开发同学）

`项目汇报` 之外的发布包里带 Python 运行时，解压后双击：

```
启动-答辩演示.cmd    模拟数据，端口 8770，自动开浏览器
启动-真机演示.cmd    输入 COM 口，真机数据，端口 8771
关闭演示服务.cmd     关闭后台服务
```

> 便携包不入库（含 21 MB 运行时）。仓库里跑源码见方式二。

### 方式二：源码

```bash
# 依赖：Python 3.9+，仅 pyserial（可选 requirements-optional.txt）
python 项目文件/live_bridge.py --source mock  --port 8770     # 模拟
python 项目文件/live_bridge.py --source serial --serial-port COM5 --baud 115200 --port 8771
```

浏览器打开 `http://127.0.0.1:8770/`，点左上角**「开始推流」**（页面默认静止，不点不动）。

真机需先完成 4 分半三段校准：闭眼 30 秒 → 睁眼静坐 2 分钟 → 闭眼放松 2 分钟；未校准不进入判别。

## 6. 明确的边界（不回避）

- **不宣称准确率**。没有金标准标签，任何准确率数字都是假的。能证明的是：规则可追溯、结果可复现、两套实现一致——这是"可检验"，不是"正确"。
- **只有 1 名受试者**，不谈跨人泛化；换人必须重新校准，这是设计的一部分。
- **本机硬质头环无 PPG**，压力依赖 HRV，因此真机上压力格恒显示"—"。软头环有 PPG 即可判。
- **实验未完成**：平台、指标、脚本就绪，但有效性结论需要 4–6 名受试者、每人两轮共 40 次决策。
- **不做诊断、不做投资建议**。定位是"提醒层"，不是医疗器械。

## 7. 数据与隐私

- 受试者原始脑电数据**不入库**（`.gitignore` 已排除 `项目文件/data/`），仓库内不含任何受试者数据。
- 运行时全部本地，不上传云端。
- 演示使用合成数据，按真机分布生成，判别算法与真机完全同一套。
- 实验平台对受试者隐藏实验条件，避免破盲。
